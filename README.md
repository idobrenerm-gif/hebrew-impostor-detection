# hebrew-prompt-language-detection
Can you tell, from a Hebrew text generated by an LLM, which language the prompt was written in? Synthetic Hebrew texts from several LLMs, prompted in 8 languages (Hebrew, Arabic, Persian, Russian, Chinese, English, French, Spanish). Binary task (Hebrew vs. non-Hebrew prompt) and multi-class prompt-language identification; comparing TF-IDF, fine-tuned DictaBERT/AlephBERT, zero/few-shot LLMs and LoRA, with a focus on cross-generator generalization. Course project, LLMs &amp; Applications, Bar-Ilan University.
