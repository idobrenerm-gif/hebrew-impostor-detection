# hebrew-impostor-detection
Detecting LLM-generated content impersonating Israelis on Hebrew social media. Synthetic persona-based data from multiple LLMs vs. authentic Hebrew posts; comparing TF-IDF, fine-tuned DictaBERT/AlephBERT, zero/few-shot LLMs and LoRA, with a focus on cross-generator generalization. Course project, LLMs &amp; Applications.
