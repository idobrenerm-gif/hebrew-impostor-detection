## Motivation
LLMs are often prompted in one language and asked to write in another. A foreign actor who wants Hebrew content (e.g. an influence operation) is likely to write the prompt in their own language and ask the model to answer in Hebrew. If the prompt language leaves a detectable trace in the Hebrew output, it can serve as an attribution signal: not only "is this AI-generated?" but "was it produced by someone working in another language?".

## Task
Given a Hebrew text generated by an LLM, identify the language of the prompt that produced it.

- **Input**: a single Hebrew text generated by an LLM.
- **Primary task (binary)**: was the prompt written in **Hebrew** or in **another language**? (D-013)
- **Secondary task (multi-class, 8 classes)**: which prompt language produced the text? (D-013)
- **Prompt languages** (D-014): Hebrew, Arabic, Persian, Russian, Chinese, English, French, Spanish.
- **Ground truth**: known by construction, since we write the prompts.

## Data
- Fully synthetic: Hebrew texts generated by several LLMs from prompts in each of the 8 prompt languages. No human-written class (D-015).
- How prompts are produced and translated, which generators are used, text genres and dataset size: TBD (see `OPEN_QUESTIONS.md`).

## Methods to compare (D-005)
1. Baseline: TF-IDF + logistic regression.
2. Fine-tuned Hebrew encoders: DictaBERT / AlephBERT.
3. LLM zero-shot / few-shot.
4. LoRA fine-tuning of a small LLM.

## Research question (D-006)
Does a classifier trained on data from one generator model generalize to another generator (**cross-generator generalization**)?

Additional research questions are under discussion (see `OPEN_QUESTIONS.md`).

## Known challenges
- **Weak signal**: strong models may write fluent Hebrew regardless of the prompt language, so the classes may be close to inseparable.
- **Content shortcuts**: prompts in different languages may differ in content (names, cultural context, examples), letting the classifier learn content instead of prompt-language traces.
- **Trivial leakage**: the model may leave words or script from the prompt language in its output, which turns the task into plain language ID.
- **Length and format**: prompt language may change output length or structure, which is also a shortcut.

## Out of scope (D-008)
- Explaining linguistic cues is not a measurable goal. At most, it remains a qualitative analysis.
