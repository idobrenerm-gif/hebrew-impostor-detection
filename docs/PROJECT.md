# Project Overview

Final project for the course **"Large Language Models and Their Applications"**, Bar-Ilan University.
Team: Ido Brenner, Oren.

## Course requirements
- Solve a novel, relevant task using LLMs / GenAI.
- Recommended approach: a task with no existing dataset, so synthetic data is generated for training and evaluation.
- Compare several methods: fine-tuned models vs. off-the-shelf models.
- Proposal: a 5-slide presentation:
  1. Motivating Use Case (background, importance, challenge, current solutions)
  2. Task Description (formal definition, input/output, novelty)
  3. Models & Methods (pipeline, models per stage, fine-tuning)
  4. Data (requirements, sources, labeling, synthetic data and how it is generated)
  5. Metrics & KPIs (metrics, per-stage quality, ground truth)

## Problem
Foreign influence operations run profiles impersonating Israelis on Hebrew social media, and a growing share of their content is LLM-generated.

## Task
Binary classification: **impostor** vs. **authentic**, at two levels:
- **Post level** — a single post.
- **Account level** — a collection of posts from one account.

## Data
- **Impostor class**: synthetic posts generated by several LLMs using Israeli personas. Possible extension: "translated" Hebrew — machine translation of posts originally in Arabic, Persian or English.
- **Authentic class**: real Israeli posts, from an existing dataset if one exists, otherwise collected manually by Ido and Oren. Source and topic are recorded for every post.

## Methods to compare
1. Baseline: TF-IDF + logistic regression.
2. Fine-tuned Hebrew encoders: DictaBERT / AlephBERT.
3. LLM zero-shot / few-shot.
4. LoRA fine-tuning of a small LLM.

## Research question
Does a classifier trained on data from one generator model generalize to another generator (**cross-generator generalization**)?

## Known challenges
- **Shortcut learning**: the classifier may learn topic or generator style instead of "impersonation". Mitigation: topic matching between the classes.

## Out of scope
- Explaining linguistic cues is not a measurable goal. At most, it remains a qualitative analysis.
