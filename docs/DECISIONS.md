## D-012 — Pivot: detect the prompt language of LLM-generated Hebrew text
- Date: 2026-11-11
- By: both
- Status: Active
- Decision: Drop the impostor-detection direction. New task: given a Hebrew text generated by an LLM, identify the language of the prompt that produced it. Supersedes D-001, D-002, D-003, D-004, D-007 and D-011. D-005 (methods), D-006 (cross-generator research question), D-008 and D-009 remain active.
- Why: Lecturer feedback on the proposal: the intent to impersonate cannot be inferred from the text, which makes the v1 task much weaker than plain "AI vs. not AI". The lecturer suggested the prompt-language direction. The new task has ground truth by construction and keeps the methods and the cross-generator question.

## D-013 — Task structure: binary primary task, multi-class secondary task
- Date: 2026-11-11
- By: Ido
- Status: Active
- Decision: Primary task is binary (Hebrew prompt vs. non-Hebrew prompt). Secondary task is multi-class identification of the prompt language (8 classes, see D-014). Text-level only; no account level.

## D-014 — Prompt languages
- Date: 2026-11-11
- By: Ido
- Status: Active
- Decision: 8 prompt languages: Hebrew, Arabic, Persian, Russian, Chinese, English, French, Spanish. The output is always Hebrew.
- Why: Covers languages relevant to influence operations (Arabic, Persian, Russian, Chinese), widely used languages (English, French, Spanish), and a range of distances from Hebrew.

## D-015 — No human-written class
- Date: 2026-11-11
- By: Ido
- Status: Active
- Decision: All data is LLM-generated. No human-written Hebrew class.
- Why: Keeps the task focused on prompt language and avoids manual data collection.
